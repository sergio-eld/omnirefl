## Breaking changes

Examples, tests, and benchmarks are now distributed separately as
`omnirefl-extras-0.0.6-<commit>.tar.gz`; they are no longer included in the tool
packages under `share/omnirefl/`. Download and extract the extras archive to run
them. In source checkouts, `share/` is now `extras/`.

## Package integration

- Add CMake FetchContent integration for downloading a verified release archive
  or building a selected commit through Docker Compose.
- Add a Conan 2 recipe for prebuilt Cosmo packages and commit-based Docker builds.
- Remove the Git requirement for fetching dependencies of the examples, tests,
  benchmarks, and serialization extension.

## JSON/YAML serialization

- Allow `as_json` and `as_yaml` to serialize supported scalars and vectors at the
  document root, including nested vectors and vectors of reflected records.
- Support char-based `std::basic_string` variants, c4 string views, and
  `std::basic_string_view` where available.
- Improve serialization and deserialization performance without changing their
  public interfaces.

## Fixes and diagnostics

- Fix reflection with CMake-managed precompiled headers, including MSVC and
  clang-cl include ordering, Windows paths in the Cosmo tools, and regeneration
  after changes to headers included through a PCH wrapper.
- Fix compile-command selection when `compile_commands.json` omits `output` but
  supplies the object path through `-o`.
- Fix Cosmo crashes on macOS systems with raised stack limits.
- Reject reflected targets configured below C++11 during CMake configuration,
  instead of allowing later compilation failures. The target's standard is not
  changed automatically.
- Improve diagnostics when the compilation database is missing or the CMake
  generator cannot produce it.
- Include the LLVM version in `omnirefl --version`; add `ccdb_query --version`.
