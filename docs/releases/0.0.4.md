## Highlights

- Add experimental, C++11-compatible JSON/YAML serialization backed by RapidYAML, with configurable recovery and retained diagnostics.
- Add function reflection: documentation, parameters, and return types for supported member functions and free functions discovered through tagged record fields.
- Expose supported field default values, with warnings when an initializer cannot safely be reproduced.
- Package examples, tests, and benchmarks as a runnable CMake project; individual examples remain self-contained.
- Refresh the README and landing page, improve mobile navigation, and expand distribution CI coverage.
- Fix compilation-database handling of invalid paths and Windows command-line definitions.

Omnirefl remains in early development. Compatibility is not promised before 0.1.0, planned after the planned extensions are complete.
