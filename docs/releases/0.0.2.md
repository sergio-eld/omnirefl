## Highlights

- Add an experimental universal Cosmopolitan package with x86_64 and AArch64 tools for Linux, macOS, and Windows. The package includes the required Clang, libc++, and platform headers.
- Move macOS SDK discovery into CMake configuration and remove per-invocation `xcrun` execution from Omnirefl.
- Add `omnirefl/functional.hpp` with C++11-compatible eager and pipeable compositors for tuple-like data, including filtering, mapping, folding, concatenation, and field-based selection.
- Add experimental code-generated `omni::refl::aggregate_into<T>` for strict, shallow, name-based aggregate projection.
- Preserve `reflected_call` argument value categories and define `std::move(field).value()` as the canonical consuming field-binding operation.

## Packaging and CI

- Expand package testing across Linux musl, Cosmopolitan, macOS Intel and Apple Silicon, Windows UCRT, and supported Windows toolchains.
- Add record-conversion benchmarks for trivial and move-only data across raw and ranges-based batch strategies.
- Publish the README-backed project site through GitHub Pages and persist continuous benchmark history by system, architecture, libc, and toolchain.
- Harden releases with exact artifact and file validation, SHA-256 digest verification, detached debug-symbol archives, checksums, and attestations.
- Reuse verified artifacts from successful protected-`master` CI runs for tagged releases, with an automatic full-validation fallback when reuse is unavailable.

## Infrastructure

- Add C++23 standard-library compatibility utilities required by the Cosmopolitan build.
- Add dependency-free CMake scaffolding for future opt-in extensions and shared examples.
- Improve focused diagnostics and negative coverage for unsupported aggregate projections, missing or incompatible fields, unions, and aggregates with bases.

## Notes

- `omni::refl::aggregate_into<T>` and the Cosmopolitan distribution are experimental.
- Aggregate projection is currently shallow; every destination public field must have a same-named constructible source field unless the input is explicitly completed first.
- Windows AArch64 packaging remains unsupported by the current MinGW toolchain.
- The first Apple Silicon Cosmopolitan invocation may require Xcode command-line tools to build the embedded `ape-m1` loader.
