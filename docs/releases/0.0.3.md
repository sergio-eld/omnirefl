This release clarifies the reflected-scope API before 0.1.0, improves dependency discovery, and replaces the introductory example with a more representative end-to-end demonstration.

> Omnirefl remains in active testing and interface polishing. Compatibility is not promised before 0.1.0; breaking changes will continue to be documented in release notes.

## Breaking changes

- Replace `#include <omnirefl/reflection.hpp>` with `#include <omnirefl/reflected_scope.hpp>`.
- Metadata wrappers now receive an opaque generated metadata type. Use their public `reflected_type` alias instead of depending on generated internals.
- Use `omni::meta_for<T>` when metadata is needed in a type context. `omni::reflected(omni::type<T>)` remains the value-expression form.
- Field bindings now preserve the bound record's cv-qualification separately from field metadata.
- Rename field type-text queries:
  - `type_name()` → `spelled_type_name()`
  - `qualified_type_name()` → `spelled_qualified_type_name()`
- `omni::refl::get` now deduces the destination type from the destination field metadata. Use `get<FieldMeta>(fields)` instead of supplying a second type argument.

## Reflection and dependency discovery

- Clarified the public contracts for record and enum metadata, bindings, reflected scopes, field access, mutation, and consuming access.
- Full declaration comments are now preserved in generated metadata instead of only the brief portion.
- Improved best-effort diagnostics for reflection queries used outside a reflected scope.
- Hardened dependency discovery through aliases and primary-template specializations.
- Incomplete or unsupported dependency candidates are skipped with diagnostics instead of being treated as reflected types.
- Added direct eager and pipeable `fn::filter<Predicate>()` support for C++20 structural predicates.

## Documentation and Pages

- Reworked the Sneak Peek around a single `.cpp` example demonstrating primary templates, nested records, dependency discovery, field aliases, documentation, namespace-aware names, functional traversal, bit-fields, and mutation through const records where allowed.
- Added an explicit project-status notice and refreshed the generated landing page.
- Pages preview metadata now comes from the README slogan and includes the project banner for link previews.
- Site-only changes skip package builds, tests, and benchmarks while preserving release artifact reuse and benchmark history.
